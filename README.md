# Algorithms Repository

A comprehensive collection of algorithm implementations and data structure exercises in C++, designed for learning and practicing competitive programming concepts.

## 📋 Overview

This repository contains **86 programming exercises** covering various algorithmic concepts and problem-solving techniques. Each exercise is implemented in C++ and focuses on fundamental to advanced topics in computer science and competitive programming.

The exercises are written with Georgian language problem descriptions, making this resource particularly valuable for Georgian-speaking developers and students learning algorithms and data structures.

## 📁 Repository Structure

```
Algorithms/
├── Exercise1/ - Exercise91/      # Numbered exercise folders (86 total)
├── Graphs/                        # Graph theory implementations
│   ├── Loop/                      # Loop detection in graphs
│   ├── Neighbor matrix/           # Adjacency matrix representation
│   └── Tsiboebis Raodenoba/       # Graph counting problems

│   ├── Digits Sum/                # Sum of digits

│   └── Reverse Array/             # Array reversal using recursion
└── ALGORITHMS_EXERCISES_REPORT.md # Comprehensive catalog of all exercises
```

## 🎯 Topics Covered

The exercises span multiple fundamental computer science topics:

### Core Concepts
- **Basic Programming**: Arithmetic operations, input/output, conditionals, loops
- **Recursion**: Factorial, digit sum, array operations, power calculations
- **Dynamic Programming**: Optimization problems, memoization techniques
- **Sorting Algorithms**: Various sorting techniques and implementations
- **Graph Theory**: Loop detection, adjacency matrices, graph traversal

### Learning Path
1. **Beginner** (Exercises 1-20): Basic programming constructs and simple algorithms
2. **Intermediate** (Exercises 21-50): Recursion, sorting, and problem-solving techniques
3. **Advanced** (Exercises 51-91): Dynamic programming, graph algorithms, and complex problems

## 🚀 Getting Started

### Prerequisites
- C++ compiler (GCC 5.4+ or Clang 3.8+)
- Basic understanding of C++ syntax
- Familiarity with standard template library (STL)

### Compilation
Each exercise can be compiled using g++:

```bash
# Navigate to an exercise directory
cd Exercise1/

# Compile the C++ file
g++ -o exercise1 exercise1.cpp

# Run the executable
./exercise1
```

### Alternative compilation with optimization:
```bash
g++ -std=c++14 -O2 -Wall exercise1.cpp -o exercise1
```
